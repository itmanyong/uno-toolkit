## 原始观察（事实陈述，非判定）

1. 同 task 1000 次异值写：文本通道与结构通道均合并为 1 次 DOM 写 / 1 次 commit（事务去重 §15.3 与 React 批处理各自生效）。
2. 同值写 1000 次：DOM 写 0 次（值级抑制生效，符合 §15.3 表格 B 方案行为）。
3. 纯文本路径 React commit 恒为 0（S1 三个 Round 一致）。
4. Block 结构通道每次 commit 伴随 3 次 render 闭包执行（见构成说明）；Profiler commit 次数与写入轮数 1:1。
5. jsdom 单写端到端延迟量级：文本通道 Round C mean 0.0046 ms；Block 0.1565 ms；useState 基线 0.0956 ms。三者均为同 task 微任务/宏任务调度的墙钟差，含 jsdom 模拟开销，不代表浏览器表现。
